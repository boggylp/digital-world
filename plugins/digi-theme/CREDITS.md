# Credits

## Sprites

The sprites in `sprites/`, and the pixel data generated from them in `src/sprites.generated.ts`, come from [Full Color Digimon Dot Sprites](https://withthewill.net/threads/full-color-digimon-dot-sprites.25843/) by Tortoiseshel, shared on With the Will. The thread states: "These sprites are all free for anyone to use."

They are full-color versions of the dot sprites from Bandai's Digimon virtual pets.

## Digimon UP collection

The collection in `assets/digimon-up/` supplies the animations in `src/up-images/`. The original images remain at full resolution. It comes from [dannyphang/digimon-up-sprites](https://github.com/dannyphang/digimon-up-sprites/tree/a924c32404f86e2cde11f5420d2980e693aa2f02), revision `a924c32404f86e2cde11f5420d2980e693aa2f02`.

The upstream README is preserved as [UPSTREAM.md](assets/digimon-up/UPSTREAM.md), alongside the animation table and correction metadata. It attributes the artwork to Bandai Namco and describes the collection as a non-commercial fan project shared for fan use only. This project's MIT license excludes these assets.
